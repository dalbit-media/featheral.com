Separate data, separate purpose

FTH$ remains in append-only, UTC daily JSONL files. Each block links to its predecessor and can be verified independently. SQLite is used only for a derived query index; the files remain authoritative.

World feeds and wallet profile metadata are managed by the in-process DB API with Node's built-in SQLite. They are not written to the FTH$ currency ledger.

Old profile entries in existing FTH$ blocks remain part of the immutable historical record. New profile updates are stored in the database service.
