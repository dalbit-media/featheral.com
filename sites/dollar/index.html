How FTH$ works

Ethereum MainnetFTHGFixed-supply ERC-20. Balances and transfers live only on Ethereum. Open Featheral Gold →
⇄
Bridge rate1 FTHG = 1,000 FTH$Opening rate. A constant-product bridge curve sets the price once the pool is funded.
⇄
Layer 3FTH$Native block ledger. Credits are sealed only after the bridge transaction confirms on Mainnet.
01 · Convert

FTHG → FTH$

Convert FTHG on the Ethereum bridge contract. Once the transaction confirms, the writer node seals a CREDIT to your wallet's FTH$ account.

02 · Spend & send

Free transfers

Sign a plain-text message in your wallet — no gas. The writer verifies the signature and a strictly increasing nonce, then seals a TRANSFER within about a second.

03 · Withdraw

FTH$ → FTHG

Withdrawals are RESERVED on the ledger, paid in FTHG by the bridge on Ethereum, then SETTLED with the Mainnet transaction hash. Cancelled requests are RELEASED.

An open, replicable ledger

Storage format

Layout
YYYY/YYYY-MM-DD.jsonl — one folder per year, one file per UTC day
Encoding
One block per line, canonical minified JSON (sorted keys)
Block hash
sha256(canonical({h, t, p, x})) chained via p
Signatures
Ed25519 writer signature S over each block hash
Topology
One writer node, any number of read replicas

Run a read replica

Replicas pull blocks from /api/v1/fth/sync, re-verify every hash, signature and transaction, and serve the same public API. Past day files are immutable and safe to cache or mirror.

FTH_LEDGER_MODE=reader
FTH_LEDGER_UPSTREAM_URL=https://dollar.featheral.com
FTH_LEDGER_WRITER_PUBLIC_KEY=<writer key>
npm start
