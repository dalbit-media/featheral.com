# Featheral
## 탐험과 정착지 성장으로 경험하는 Web3 거버넌스

[English white paper](./WHITEPAPER.md)

**상태:** 연구 초안이자 플레이 가능한 프로토타입입니다. 토큰 투자 제안서가 아닙니다.

**기본 재화:** 페더럴 달러(FTH$). **골드:** 페더럴 골드(FTHG)는 향후 Ethereum 연동 토큰으로 준비 중인 별도 오프체인 재화입니다.

**검토 중인 네트워크:** 이더리움. 현재 배포된 토큰은 없습니다.

> Featheral은 서버 기반의 가상 경제를 사용하는 싱글플레이 시뮬레이션입니다. 실제 DAO, 투자 상품, 금전적 보상 서비스 또는 현실의 정치적 권한을 행사하는 시스템이 아닙니다. 게임의 자원, 주민, 거래소, 투표, 보상은 모두 가상입니다.

## 1. 우리가 만들고 싶은 경험

Web3 거버넌스가 어렵게 느껴진다면 게임으로 먼저 경험해 보세요. Featheral은 직접 탐험하고 키워 나가는 작은 월드에서 출발합니다.

정착지를 세우고 주민을 모집하세요. 자원지에 채집팀을 배치하고, 창고를 확장하고, 우호도를 높여 연방에 가입할 수 있습니다. 가상 의회에서는 어떤 안건을 우선할지 고민하며 함께 결정하는 방식을 경험합니다.

이 프로토타입의 목표는 자원 조정과 공동의 의사결정에 관한 질문을 가벼운 브라우저 게임으로 만나게 하는 것입니다. 학습을 위한 실험 공간이지, 특정 거버넌스 모델이 현실에서도 작동한다는 증거가 아닙니다.

### 설계 원칙

- **전문 용어보다 경험을 먼저 제공합니다.** 눈에 보이는 행동과 익숙한 게임 흐름으로 설명합니다.
- **클릭 수보다 시간이 중요합니다.** 자원 생산은 신뢰할 수 있는 서버 시간을 따릅니다.
- **자원의 소유 상태를 구분합니다.** 수령 대기 중인 생산량과 이미 수령한 보유 자원은 다릅니다.
- **플레이 조건을 명확하게 안내합니다.** 저장 한도, 인구 조건, 주민 모집 소요 시간을 확인하고 다음 행동을 선택할 수 있습니다.
- **결제 없이 플레이합니다.** 지갑 연결, 결제, 가스비, 토큰이 필요하지 않습니다.
- **프로토타입의 한계를 명확히 안내합니다.** 구현된 기능, 연구 방향, 미배포 토큰 콘셉트를 구분합니다.

## 2. 지금 플레이할 수 있는 것

익명 브라우저 세션마다 독립적으로 생성된 월드에서 플레이합니다. 다음 활동을 할 수 있습니다.

1. 육지에 정착지를 세우고 주민 탐험대로 21가지 지형을 탐험합니다.
2. 자원별 자동 배치를 활용하거나 인원을 수동으로 조정하고 주간 채집량을 받습니다.
3. 창고를 건설하고 확장합니다.
4. 가상의 주민을 모집하고 정착지를 업그레이드합니다.
5. 전용 거래소에서 국제 원자재 단위로 수량·단가를 확인하고 FTH$ 시장가 또는 지정가 주문으로 거래합니다.
6. 인벤토리에서 시야 장비를 제작·장착하고, 조건을 충족하면 도시 은행과 마을 회관을 건설합니다.
7. 우호도를 높이고 가상의 연방에 가입하거나 연방 창설 조건을 달성합니다.
8. 하천 유역 복원 안건에 가상 투표로 참여합니다.

정착지 운영은 **싱글플레이**이며 실시간 협동 멀티플레이가 아닙니다. 거래소와 채팅은 같은 서버의 다른 브라우저 세션과 연결됩니다. **메시지함**에는 현재 탐험 시야 안의 정착지 탐험 공개 채팅과 해당 정착지가 속한 연방의 공개 채팅이 표시됩니다. 이동 중에도 내 정착지 공개 채널은 이용할 수 있습니다. **연락처**는 아바타 메뉴에 있으며 탐험 지도에서도 같은 공개 채널을 열 수 있습니다. 정착지 페이지의 방문자 단체 채팅은 공개 메시지함에 표시되지 않습니다. 가까운 정착지를 방문해 참여한 누구나 대화할 수 있으므로 암호화된 비밀 대화나 초대 전용 채팅으로 생각하면 안 됩니다. 방마다 최근 메시지 100개를 보관하고 3초마다 1개를 보낼 수 있으며 단일 API 프로세스에서 총 1,000명이 접속합니다. 공개 채널은 전달 직전에 시야 조건을 다시 확인하고 방문 이력·방별 메시지는 재시작 후에도 유지합니다. 방문 시 공개 닉네임·좌표·인구만 제공하며 다른 플레이어의 잔액·자원·운영 권한은 공개하지 않습니다. 주민·거버넌스는 가상이며 연방 가입으로 온체인 조직이 만들어지지 않습니다.

### 성장 단계

| 성장 단계 | 업그레이드에 필요한 인구 |
|---|---:|
| 정착지 | 인구 조건 없음. 건설 시 첫 주민 12명 제공 |
| 야영지 | 25명 |
| 주거지 | 80명 |
| 마을 | 250명 |
| 소도시 | 800명 |
| 도시 구역 | 2,500명 |
| 도시 | 10,000명 |
| 대도시 | 25,000명 |
| 수도 | 100,000명 |

각 업그레이드에는 자원도 필요하며 정확한 비용은 게임에 표시됩니다.

늘푸른 연합 가입에는 마을 이상의 단계와 우호도 50이 필요합니다. 친선 물자로 목재 4 m³와 물 0.3 m³를 보내면 우호도가 25 올라갑니다. 우호도 상한은 100입니다.

초록빛 연방 창설에는 도시 이상의 단계, **10,000명을 초과하는 주민**, 금속 50 t가 필요합니다. 연방 창설은 컨트랙트 배포가 아닙니다.

연방에 가입하고 마을 회관을 갖춘 소도시 이상은 현재 안건에 한 번 투표할 수 있습니다. 실제 온체인 집계, 정족수, 재정 집행, 법적 대표 권한은 없습니다.

### 거래소

전용 페이지 `/play/market/`는 원자재 4종·제작 아이템 10종·기념품 21종·자동화 이용권 18종(수거권 12종·탐험권 3종·주민 모집권 3종)의 **53개 마켓**을 제공합니다. 기념품을 제외한 모든 자산은 같은 종류끼리 교환 가능한 유동 자산이며, 동일한 준비금 공식·1% 스프레드·플레이어 주문 체결로 수요에 따라 가격이 달라집니다. 잔액과 보관함 범위에서 최대 10,000개를 정수 수량으로 거래하며 아이템 1개당 가방 1칸을 사용합니다. 같은 장비·장식을 추가 제작할 수 있고, 장착·배치 중인 1개는 보호하되 여분은 판매할 수 있습니다. 기념품은 종류별 1개만 보유하고 플레이어 주문으로만 거래하며 주문이 없으면 호가도 표시하지 않습니다. 기존 기념품 시스템 풀을 폐쇄하고 준비금을 아이템 풀로 한 번 재배분합니다. FTH$ 추가 발행 없이 총 준비금·통화 정책 상수·주문·거래 기록을 보존합니다.

카드 보기에는 자원·아이템 이미지, 분류, 보유량, 매수·매도 FTH$ 호가를 구분해 표시합니다. 거래 가능한 호가가 없으면 가짜 가격 대신 호가 없음으로 표시합니다. FTH$/FTHG 환전은 거래소에서 분리한 **페더럴 은행**(`/play/bank/`)에서 이용하며, 계정 메뉴의 FTHG 카드에서 바로 이동할 수 있습니다.

### 페더럴 은행: 준비금 기반 장기 스테이킹

FTHG를 **게임 시간 1·2·5·10·20·30년** 동안 예치하고 FTH$ 단리 이자를 받습니다. 게임 1년은 정확히 52주이며 정식 서버에서는 실제 6일 1시간 36분, 개발 20배속에서는 7시간 16분 48초입니다. 실제 소요 시간과 예상 만기를 함께 표시합니다. 서버 배속이 변경되어도 저장된 게임 시간 만기는 그대로 유지됩니다.

예치 시 골드 준비금 풀의 기준 환율로 FTH$ 환산 금액을 확정하며 소수점 넷째 자리에서 내림합니다. 이자는 `floor(환산 금액의 하위 단위 × 연이율 bp × 예치 연수 / 10,000)`이며 복리를 적용하지 않습니다. 환산 금액·확정 연이율·원금·총이자·기간이 승인한 조건과 정확히 일치해야 접수합니다. 이후 환율이나 금리가 바뀌어도 기존 예치 조건은 변경하지 않습니다.

서버가 임명한 은행 의회 구성원 전체의 과반수 찬성으로 연이율을 확정합니다. 구성원은 안건별로 한 번만 표결하고 제안자의 찬성표를 포함합니다. 금리는 0~100% 범위에서 0.01% 단위로 제안할 수 있습니다. 의회 구성 변경 시 진행 중인 안건은 취소하고 신규 금리는 신규 예치에만 적용합니다. 의회·양의 확정 금리·충분한 준비금이 없으면 스테이킹을 접수하지 않습니다.

이자는 자발적으로 기부한 **기존 FTH$**에서만 지급합니다. 기부금은 회수할 수 없으며 예치 접수 전 기간 전체의 이자를 원금과 분리해 확보합니다. 만기에는 원래 FTHG 원금과 확보된 FTH$ 이자를 한 트랜잭션으로 수령합니다. 중도 출금, 신규 통화 발행, 원금을 사용한 이자 지급은 허용하지 않습니다. 이자 준비금과 예치 원금은 계속 총공급량에 포함합니다.

게임 내 기능이며 이더리움 온체인 스테이킹이나 실제 수익을 보장하는 금융 상품이 아닙니다. 미수령 예치와 의회 계정은 일반 세션 정리 대상에서 제외하고 은행 접속 시 최대 400일의 브라우저 쿠키를 갱신합니다. 익명 계정이므로 브라우저 계정 정보를 삭제하면 접근 권한을 잃을 수 있습니다. 내보낸 기록으로 인증이나 잔액을 복구할 수는 없습니다.

### 거래소 주문·환전 정산 규칙

플레이어 지정가는 가격 우선, 같은 가격에서는 접수 순서대로 체결되며 자기 주문과 체결되지 않습니다. 시스템 상수곱 풀은 매수·매도 각각 1% 스프레드를 적용합니다. 정확한 BigInt 연산으로 매수는 올림, 매도는 내림하여 FTH$0.0001 단위로 정산합니다. 시장가는 견적 대비 총액 기준 최대 2% 변동만 허용하며 전량 체결되지 않으면 지출 없이 거절됩니다. 초기 풀은 원자재별 회계 수량 100,000단위, 아이템별 1,000개와 기준가에 해당하는 FTH$로 시작합니다. 금속은 스프레드 적용 전 FTH$200/t이며 고정 환율이 아닙니다. 실제 금융 자산으로 뒷받침되지 않는 유한한 게임 내 준비금입니다.

매수 주문은 FTH$, 매도 주문은 보유 자산을 예치합니다. 부분 체결 후 미체결분만 남고 취소하면 반환됩니다. 아이템 주문은 인벤토리 공간을 예약합니다. 세션당 미체결 주문은 최대 50개이며 7일 세션 만료와 함께 만료됩니다. 원자재는 회계 수량 1~10,000단위입니다. 화면에서 목재는 0.1~1,000 m³를 0.1 m³씩, 물은 0.01~100 m³, 금속은 0.01~100 t를 각각 0.01씩, 석유는 1~10,000 bbl을 입력합니다. 일반 아이템은 정수 개수, 고유 기념품은 1개씩 거래합니다. 지정가 한도는 회계 단위당 FTH$0.0001~1,000,000이며 표시 단가와 입력 간격은 목재 10배, 물·금속 100배, 석유·아이템 1배로 환산합니다. 차트는 실제 체결 120건만 제공하며 시세는 5초마다 갱신됩니다. 양쪽 계정·예치금·준비금·체결·재시도 기록은 SQLite 트랜잭션으로 저장합니다.

FTH$와 페더럴 골드(FTHG)는 별도 잔액이며 각각 1단위를 정수 하위 단위 10,000개로 저장합니다. API는 일반 수치를 사용합니다. 골드는 향후 Ethereum 연동 토큰으로 준비 중이며 거래소 기본 재화가 아닙니다. 별도 준비금 풀에서 골드 0.0001~10,000개를 사고팔 수 있습니다. 변동 기준 환율, 매수·매도 각각 1% 스프레드, 확인 금액 대비 최대 2% 시세 보호를 적용합니다. 새 세계의 풀은 골드 1,000개와 FTH$1,000,000으로 시작하므로 최초 기준 환율은 골드 1개당 FTH$1,000입니다. 거래에 따라 환율이 움직이고 수수료는 풀에 남습니다. 기존 세계는 이전 거래소의 골드 준비금을 보존하고 같은 초기 기준 환율에 맞춰 FTH$ 준비금을 설정합니다.

버전 4 전환에서는 보유·수령 대기 리튬을 FTH$로 1:1 전환하고 기존 골드 잔액을 보존합니다. 이전 골드 주문은 취소하며 매수 예치금은 골드로, 매도 자산은 원래 자원·아이템으로 반환합니다. 유료 자원 작업과 탐험 복귀 시각은 유지하되 리튬 채집팀과 배치는 제거합니다. 이전 골드 풀·주문·체결·재시도 기록은 `legacy_gold_market_*`에 별도 보관하며 FTH$ 이력에 섞지 않습니다. 이후 적용된 무발행 규칙에 따라 주간 수입은 지급하지 않습니다. 오래된 요청 기록과 리비전을 무효화합니다. 잔액이나 예치금이 잘못되면 전체 전환을 되돌리며 재시작 시 중복 환급하지 않습니다.

### 한정된 FTH$ 잔액과 소비

신규 플레이어와 처음 정착한 정착지는 **FTH$0**으로 시작합니다. 주민·은행·상업 건물·탐험으로 FTH$를 지급하지 않으며, 오프라인 시간이나 기존 탐험에도 보상을 지급하지 않습니다. 기존 잔액·건물·유료 작업·재시도 기록은 보존하고 과거 비용은 환급하지 않습니다. 새 규칙은 오래된 신규 행동 리비전을 한 번만 무효화합니다.

주민 모집 비용은 기존처럼 **합류 인원 1명당 FTH$50**입니다. 탐험도 거리·난이도에 따른 FTH$ 비용을 내지만 통화 보상 대신 지역 발견과 수집품을 얻습니다. 운송비와 업그레이드는 FTH$를 소비합니다. 자원 판매는 플레이어 매수 예치금이나 거래소 풀의 기존 준비금을 판매자 잔액으로 옮기며, 골드 교환도 기존 준비금을 사용합니다. 최초 거래소 준비금은 한 번만 설정하고 게임 플레이로 보충하지 않습니다. 게임 행동으로 FTH$를 새로 발행하지 않으며, 이전 고정가 거래와 글로벌 통화 보상 수령은 중단합니다.

상업 건물의 보유·배치·재료 및 FTH$ 건설 비용은 유지하지만 수입은 없습니다. 노점은 야영지에서 목재 8 m³ + 금속 0.4 t + FTH$200, 상업 공방은 주거지에서 목재 20 m³ + 금속 1 t + FTH$600, 교역소는 소도시에서 목재 50 m³ + 금속 3 t + FTH$1,800입니다. 도시 은행은 석유 채집과 자원 거래를 계속 해금합니다. FTH$는 실제 달러나 온체인 토큰이 아닌 게임 재화이며 현금 출금은 지원하지 않습니다.

**정착지 → 자원 판매**는 처음 정착한 직후 은행이나 상업 건물 없이 이용할 수 있습니다. 실시간 시장가 견적을 확인하고 각 보유 자원을 `floor(보유량 / 2)`만큼 한 번에 판매합니다. 수령 대기 자원과 매도 주문 예치 자원은 제외하며, 판매량이 0이면 건너뜁니다. 절반 수량이 10,000개를 넘어도 정확하게 판매합니다. 자원마다 최대 2% 시세 보호와 기존 시장 스프레드를 적용합니다. 플레이어 주문·풀 이동·체결 기록을 포함해 전체 거래가 한 번에 성공하거나 모두 취소되며 재시도로 중복 판매하지 않습니다. 물을 판매하면 소비 예비량이 줄어드므로 확인 창의 물 부족 경고를 확인하세요.

### 고정 통화 정책 버전 1

최초 준비금을 한 번 설정한 뒤 FTH$를 새로 발행하지 않습니다. 게임 비용은 국고로 모으지 않고 **영구 소각**합니다. 거래는 보유 잔액·주문 예치금·풀 준비금 사이의 기존 재화만 옮기며 풀 스프레드는 준비금에 남습니다. 통화나 유동성이 소진되면 추가 활동이 제한될 수 있습니다. 무료 기본 채집과 주민을 보존하는 물 부족 규칙은 기본 플레이를 유지하지만 무한한 운영 자금을 보장하지 않습니다.

자원과 골드 풀은 같은 정수 기반 상수곱 공식을 사용합니다. 통화 준비금 R, 자산 준비금 S, 거래량 q일 때 매수 비용은 `ceil(R*q*101 / (100*(S-q)))`, 매도 수령액은 `floor(R*q*99 / (100*(S+q)))`입니다. R은 FTH$ 1개당 10,000의 세부 단위이며, 골드의 S·q도 세부 단위, 원자재는 정수 수량을 사용합니다. 시세 보호는 최대 2%이며 플레이어 주문은 가격·시간 우선순위를 유지합니다. 시세가 변해도 공식은 유지합니다.

고정 상수의 지문과 측정한 초기 통화량을 저장합니다. 정책 상수가 달라지거나 보유 통화 총량이 초기 한도를 넘으면 서버 시작을 거부합니다. 최초 설정 이후 새로 추가되거나 누락된 마켓의 시스템 준비금은 0으로 시작하며 FTH$를 발행하지 않습니다. 플레이어 지정가 주문은 이용할 수 있습니다. 이는 오프체인 운영 안전장치로, 미래 관리자의 변경까지 암호학적으로 막는 것은 아닙니다.

### 실용 시설 8레벨 성장

아래 재료와 FTH$에 **목표 레벨**을 곱해 최대 8레벨까지 강화합니다. 효과는 새 작업부터 적용하며 이미 지불한 채집·탐험은 유지합니다.

| 시설 | 해금 단계 | 1레벨 재료·FTH$ | 레벨당 효과 |
|---|---|---|---|
| 주거 단지 | 정착지 | 목재 6 m³ + 물 0.2 m³ + 금속 0.1 t + FTH$300 | 향후 모집 인원 +25%. 새 인구 제한 없음 |
| 저수지 | 정착지 | 목재 8 m³ + 금속 0.3 t + FTH$380 | 현재 인구의 물 1주분에 폭염 대비 50% 비축량을 더해 보관량 추가 |
| 상업 공방 | 주거지 | 목재 20 m³ + 금속 1 t + FTH$600 | 목재·금속·석유 채집량 +25% |
| 교역소 | 소도시 | 목재 50 m³ + 금속 3 t + FTH$1,800 | 실효 운송 거리 2칸 단축 |

기존 공방·교역소는 재구매 없이 1레벨로 인정하며 어떤 시설도 통화를 지급하지 않습니다. 영구 계정·세션 보존·샤딩·운영 및 신고 체계·대규모 소셜 서비스는 **다음 단계**입니다. 현재 익명 세션 7일, 최대 세션 10,000개, 채팅 동시 접속 1,000명 구조는 10억 사용자 인프라가 아닙니다.

### 업그레이드 비용과 정착지 바로 판매

처음 정착한 뒤 모든 성장 단계에는 재료와 FTH$가 필요합니다. 추가 비용은 야영지 FTH$200, 주거지 FTH$300, 마을 FTH$400, 소도시 FTH$500, 지구 FTH$600, 도시 FTH$700, 대도시 FTH$800, 수도 FTH$800입니다. 수도의 기존 FTH$ 비용은 유지합니다. 처음 정착할 때는 FTH$ 수수료가 없습니다. 자원 창고는 기존 재료에 FTH$50 × 목표 레벨, 아이템 보관함은 FTH$100 × 목표 레벨을 더해 지불합니다.

기존 FTH$ 가격이 없는 건물·시야 장비에는 재료 기준가를 더합니다. 목재 FTH$40/m³, 물 FTH$200/m³, 금속 FTH$200/t, 석유 FTH$24/bbl로, 기존 회계 단위당 4/2/2/24 FTH$와 동일한 경제 가치입니다. 추가 비용은 도시 은행 FTH$3,200, 마을 회관 FTH$1,500, 우물 FTH$280, 빗물 집수 시설 FTH$570, 양수장 FTH$1,140, 모닥불 키트 FTH$70, 횃불 FTH$120, 조명 FTH$320입니다. 수익 건물의 기존 FTH$ 비용과 탐험용 랜턴 FTH$4는 유지합니다. 이미 보유한 건물·장비는 그대로 유지하며 배치 이동과 장착에는 비용이 없습니다.

노점·교역소·도시 은행을 건설하면 정착지 → 건물·자원 관리에서 **자원 판매로 FTH$ 마련하기**를 사용할 수 있습니다. 자원·물리 수량 또는 최대를 선택하고 실시간 시장가 총액을 확인한 뒤 판매를 승인하세요. 수거한 보유 자원만 주문당 회계 수량 10,000단위까지 판매합니다. 거래소와 동일한 API·플레이어 호가·준비금 풀 체결, 풀 스프레드 1%, 최대 2% 시세 보호를 적용합니다. 은행의 별도 고정 가격은 없습니다. 대기 중인 채집량은 상단 자원 버튼의 **수거 후 판매**로 판매 대금에서 운송비를 정산할 수 있습니다. 건물 해금 전에도 전체 거래소는 이용할 수 있습니다.

가격·수거 방식 전환 시 오래된 행동 리비전을 한 번만 무효화하고 기존 잔액·건물·유료 채집팀·완료 시각은 유지합니다. 이미 지불한 운송비는 환급하거나 다시 청구하지 않으며 해당 작업은 그대로 완료합니다. 새 채집팀은 목재·물을 포함해 모든 인원의 FTH$ 운송비를 수거할 때 정산합니다.

## 3. 서버가 검증하는 게임 경제

### 자원과 채집팀

채집 자원은 목재, 물, 금속, 석유입니다. FTH$와 골드는 채집 자원이 아닌 별도 잔액입니다.

#### 국가·산업 규모의 거래 단위

| 자원 | 거래·보관 표시 단위 | 정수 회계 수량 1로 나타내는 물량 |
|---|---|---|
| 목재 | m³ | 0.1 m³ |
| 물 | m³ | 0.01 m³ = 10 L |
| 일반 금속 | 미터톤(t) | 0.01 t = 10 kg |
| 석유 | 배럴(bbl) | 1 bbl = 158.987294928 L |

석유 1배럴은 [미국 갤런 42개](https://www.eia.gov/tools/glossary/index.php?id=B)입니다. 1 t는 1,000 kg, 1 m³는 1,000 L입니다. 수량과 FTH$ 단가는 같은 국제 거래 단위로 표시하며, 주문은 목재 0.1 m³·물 0.01 m³·금속 0.01 t·석유 1 bbl 단위로 입력합니다. 아이템은 개수로 거래합니다. 실제 단위를 사용하되 건설·제작 비용은 플레이 가능한 기반시설·보급품 예산으로 단순화합니다. 금속은 특정 철강·구리·리튬 품위의 실제 선물 계약이 아니며 FTH$는 실제 달러가 아닙니다.

물리 단위 모델 버전 1은 기존 정수 수량을 다시 곱하거나 나누지 않고 위 물량을 연결합니다. 보유량·생산 대기량·소수 잔량·풀·주문·예치금·FTH$·재시도 기록을 그대로 보존하며, 표시 수량은 단위당 회계 수량으로 나누고 표시 단가는 같은 비율로 곱합니다. 초기 원자재 풀은 목재 10,000 m³·물 1,000 m³·금속 1,000 t·석유 100,000 bbl에 해당합니다. 통화 정책 버전 1과 검증 지문은 변경하지 않습니다. 적용 시점을 기록해 과거 작업과 이미 결제한 작업을 보존하며 중복 정산하지 않습니다.

**주민이 채집해야 자원이 생산됩니다.** 정착하면 주민이 자원별로 자동 배치되며, 타일을 일일이 선택할 필요가 없습니다. 발견한 자원은 정착지에서 채집량 대비 운송비가 가장 유리한 경로로 자동 연결됩니다. 조건이 같으면 가까운 경로를 택합니다. 주민 1명은 한 가지 일만 맡고 탐험용 주민 2명을 남깁니다. 자원별 채집팀이 **게임 시간 7일마다** 주간 채집량을 보냅니다.

| 자원 | 주민 1명당 기본 주간 채집량 |
|---|---|
| 목재 | 10 m³ × 성장 단계 배수 × 자원지 효율 |
| 물 | 6 m³ × 성장 단계 배수 × 자원지 효율 |
| 금속 | 1 t × 성장 단계 배수 × 자원지 효율 |
| 석유 | 14 bbl × 성장 단계 배수 × 자원지 효율. 도시 은행 필요 |

정착지의 성장 단계 배수는 1이고 자원지 효율은 80~180%입니다. 연방 가입 시 금속 채집량 보너스 20%가 적용됩니다. 새 작업은 7개 게임 날짜의 계절·날씨·기온을 반영하며 하루의 8개 날씨 구간을 모두 평균합니다. 주민당 채집량은 m³·톤의 소수점을 없애는 것이 아니라 회계 수량 단위로 내림하며, 작업 시작 시 확정합니다. 실제 산업 생산성을 그대로 재현하는 모델은 아닙니다.

새 게임은 목재 18 m³·물 25.6 m³·금속 0.8 t로 시작하고 정착 후 첫 주민 12명과 물 25.2 m³가 남습니다. FTH$는 지급하지 않습니다. 보유 자원 판매나 수거 후 판매로 운송비를 마련하세요. 모든 채집 인원의 수거 운송비를 정산합니다. 물 보관량은 주민의 기본 2주분에 폭염 대비 50% 여유를 반영하고 저수지로 늘릴 수 있습니다.

자동 배치는 탐험 중인 주민을 포함해 **전체 인구의 50% 가동률**을 목표로 하며 소수점은 버립니다. 새 채집 인원은 `max(0, min(floor(전체 인구 / 2) - 탐험 인원, 전체 인구 - max(2, 탐험 인원)))` 이내로 배치하고, 그 범위에서 인구에 맞춘 물 비축과 다음 성장·시설 재료를 우선합니다. 탐험 인원만으로 목표에 도달하면 새 채집을 쉬며 이미 출발한 탐험대를 취소하지 않습니다. 수동 변경과 시설 효과는 진행 중인 작업이 끝난 뒤 적용됩니다. 새 주민도 새 작업을 게임 시간 1주 동안 수행해야 합니다.

우선 채집팀을 배치한 뒤 50% 목표에 남은 인원만 추가 채집에 배치합니다. 주민을 한 명씩 배치할 때 운송비를 뺀 추가 자원 가치가 가장 높은 작업을 선택합니다. 가치는 거래소 실시간 시세가 아닌 고정 기준 가격을 사용하며, 남은 저장 공간에 들어가는 수량만 계산합니다. 창고가 가득 차거나 물이 부족하면 가동률이 낮아질 수 있습니다. 자동 배치 중에도 +/- 버튼, 슬라이더, 숫자 입력으로 바로 수동 배치할 수 있고, 손을 떼거나 입력을 마치거나 Enter를 누르면 저장됩니다. 수동 배치는 50%를 넘길 수 있지만 진행 중인 탐험대와 탐험용 주민 2명분을 유지해야 합니다. 운송비는 수거할 때 FTH$로 지불하며, 진행 중인 작업은 그대로 완료됩니다. 추가 채집도 게임 시간 1주가 걸리고 저장 한도에서 오프라인 처리를 멈춥니다.

모든 자원의 운송비는 **채집 완료 자원을 수거할 때 FTH$로 정산**합니다. 비용은 `배치 인원 × (1 + max(0, ceil((실효 거리 - 4) / 4)))`입니다. 기본 주민당 FTH$1에 초과 거리 4칸마다 FTH$1을 더 냅니다. FTH$가 없어도 채집은 시작할 수 있지만 수거 운송비를 내야 보유량으로 옮깁니다. 수거 후 판매는 거래소의 기존 FTH$ 판매 대금에서 운송비를 정산합니다. 창고가 가득 차면 새 작업을 쉬고, 오프라인 시간으로 통화를 생성하지 않습니다.

미배치 주민이나 연방 가입만으로는 생산하지 않습니다. 이동, 반복 클릭, 기여도, 투표로 자원이 생기지 않습니다.

### 급수 시설

정착 후 정착지 → 건물에서 아래 시설을 보유 목재·금속과 위에 안내한 FTH$ 업그레이드 비용으로 각각 한 번씩 건설할 수 있습니다. 건설 순서는 자유이며 별도의 성장 단계 조건은 없습니다.

| 시설 | 목재(m³) | 금속(t) | FTH$ | 기본 물 채집량 보너스 |
|---|---:|---:|---:|---:|
| 우물 | 6 | 0.2 | 280 | +100% |
| 빗물 집수 시설 | 12 | 0.45 | 570 | +200% |
| 양수장 | 24 | 0.9 | 1,140 | +400% |

급수 보너스는 합산되어 세 시설을 모두 지으면 물 채집량이 기본의 8배가 됩니다. 성장 단계·자원지 효율을 적용한 뒤 소수점 이하는 버립니다. 실제 물 자원지와 채집팀이 필요하며 즉시 생산·추가 유지비는 없습니다. 보너스는 새 주간 작업부터 적용하고 기존 유료 작업은 보존합니다. 창고와 저수지는 추가 물자를 보관할 공간을 제공합니다.

**주민의 일일 물 소비:** 기본 생활용수는 주민당 게임 시간 하루 **50 L**, 일주일 0.35 m³입니다. [WHO 생활용수 지침](https://www.who.int/publications/i/item/9789240015241)을 참고한 게임 서비스 수준이며 모든 가정의 실제 평균 사용량을 뜻하지 않습니다. 여름·고온·맑고 더운 날씨에는 기본의 최대 1.45배까지 증가합니다. 하루 8개 날씨 구간을 평균한 뒤 전체 주민의 소비량을 10 L 단위로 올림합니다. 보유한 물까지만 사용하며 물 부족으로 주민을 삭제하거나 유료 작업을 취소하지 않습니다.

물 배치에는 작업 중 소비할 예상 생활용수도 반영합니다. 물탱크가 가득 차 있어도 다음 주에 사용할 물을 미리 생산할 수 있으며, 실제 입고는 보유량과 수거 대기량을 합친 저장 한도를 넘지 않습니다.

| 봄 | 1.15배 | 1.15배 | 1배 | 1배 | 1.2배 |

비는 물 채집을 늘리고 야외 작업은 늦춥니다. 눈·폭풍은 대부분의 채집과 주민 유입을 줄입니다. 5°C 미만·28°C 초과에서는 작업 효율이 낮아지며, 물에는 결빙·증발 효과도 반영합니다. 모집은 주택 보너스에 기후 배수를 적용하고 확정 합류 인원당 FTH$50만 지불합니다. 이미 결제한 인원·기간은 출발 시 확정해 이후 기후로 변경하지 않습니다.

새 지역을 밝히는 탐험은 여행 기간 전체의 기후와 시드에 따라 자동 수거권 1~2개·활동 자동화권 0~2개·지형 기념품 발견 확률이 달라집니다. 악천후일수록 기대 발견량이 줄어들며 새로고침·재시작으로 결과를 다시 뽑을 수 없습니다. 발견 계획이 없는 기존 탐험은 이전의 3종 발견 규칙을 유지합니다. 기념품의 중복 제한과 발견물 초과분의 수령 대기 보관은 그대로입니다.

가상 날씨·기온은 결정적인 **게임 시간 16년 주기**로 생성합니다. 일일 소비 누적합으로 매우 긴 오프라인 기간도 정확하고 빠르게 정산하며, 주민 도착·자동화 이벤트·물이 다시 생산 가능해지는 시점에서는 정상 일정 처리를 재개합니다. 온라인과 오프라인에 같은 일일 올림 규칙을 적용하며 실제 일기예보는 아닙니다.

물은 성장·추가 채집보다 우선합니다. 주간 채집량은 수거 대기 상태로 보관하며, 활성화된 자동 수거권과 충분한 FTH$가 있을 때만 자동 입고됩니다. 일일 소비에는 보유한 물만 사용하므로 대기 중인 물은 먼저 수거하세요. 일일 소비 기한은 행동으로 초기화할 수 없습니다. 동일 시각의 주민 도착은 소비 후 처리합니다. 이전 주간 소비 데이터는 전환 후 하루의 유예를 받습니다. 오프라인에도 물 소비·채집·자동 수거·유료 작업을 정확하게 처리하고 주민은 보존합니다.

탐험 지도에는 공개 채팅, 정착지에는 방문자 채팅이 반투명 패널로 계속 표시되며 지도 조작 버튼과 운영 메뉴가 겹치지 않도록 배치됩니다. 메시지함은 별도 페이지 전체를 사용합니다. 프로필과 닉네임은 아바타 메뉴에서 설정하며 게임 소유권이나 잔액에 영향을 주지 않습니다.

메시지함·연방·연락처·활동 기록·게임 도감은 별도 페이지로 이동합니다. 연락처·활동 기록·게임 도감은 아바타 메뉴에서 열고 메시지함은 기존 소통 페이지 주소를 유지합니다. 활동 기록은 한국어 검색과 스냅샷 내보내기를 지원합니다. 게임 도감은 검색 가능한 8개 장으로 구성된 스크롤형 안내서로, 읽기 진행도와 한국어·영어 예시 스크린샷을 통해 일일 소비와 주간 작업을 설명합니다. 공개 이미지에는 실제 플레이어 정보 대신 익명 예시 데이터만 사용합니다.

FTH$는 게임 기본 재화, 금속은 건설 자원입니다. 골드는 별도 재화이며 FTH$로 교환할 수 있습니다. 두 재화 모두 현금이나 향후 토큰 지급 약속이 아닙니다.

### 탐험

세계에는 숲, 초원, 호수, 산, 원유 샘, 수정 광맥, 열대우림, 소나무 숲, 맹그로브, 들꽃 초원, 사바나, 사막, 모래언덕, 습지, 강, 해안, 구릉, 협곡, 화산, 툰드라, 빙하가 있습니다. 시드와 고도·기후·습도·하천 생성 규칙으로 다양한 지역이 만들어집니다. 시작 위치 주변에는 목재·물·금속 자원지가 보장됩니다.

이미 탐험한 타일은 즉시 이동할 수 있지만, 이동만으로 새 지역이 열리지는 않습니다. 탐험대마다 **미배치 주민 2명**과 출발 비용이 필요하며, 주민과 FTH$가 충분하면 여러 팀을 동시에 보낼 수 있습니다. 지형에 따라 게임 시간 1~3주가 걸리고 각 탐험대의 복귀 시간은 따로 표시됩니다. 탐험 중인 주민은 주간 자원 배치에 포함되지 않습니다. 이미 탐험 중인 목적지로는 중복 출발할 수 없으며, 조사 범위가 겹쳐도 새로 발견한 지역의 기여도는 한 번만 반영합니다. 기존 탐험대 한 팀의 저장 기록은 복귀 시간을 그대로 유지해 이전합니다.

탐험 출발 비용은 FTH$ `(10 + 5 × ceil(정착지에서 거리) + 5 × (소요 주 - 1)) × (진행 중인 탐험대 수 + 1)`입니다. 첫 팀은 경로 비용의 1배, 두 번째 동시 탐험대는 2배, 세 번째는 3배로 늘어나며 복귀한 팀은 다음 출발 비용에 포함하지 않습니다. 지도 클릭과 탐험 버튼 모두 같은 서버 기준 비용을 확인합니다. 플레이어가 이동해도 정착지 기준 비용은 줄지 않으며, 이미 탐험한 지역은 무료로 이동할 수 있습니다. 이미 출발한 탐험대의 비용과 복귀 시간은 그대로 유지합니다.

탐험대가 복귀해야 탐색한 지역이 지도에 표시되고, 주민을 다시 배치할 수 있습니다. 플레이어의 현재 위치는 바뀌지 않습니다. 조명은 이후 탐험대의 탐색 범위를 넓혀 주지만, 즉시 새 지역을 열어 주지는 않습니다. 호수·강·해안·빙하에는 정착지를 세울 수 없습니다.

### 아이템 인벤토리와 제작

전용 정착지 페이지 `/play/settlement/`는 탐험 지도와 같은 등각 격자·지형 색상·나무·건물 그래픽·날씨 효과를 사용합니다. 21×21칸의 정착지 부지는 성장 단계에 따라 발전하며, 건설한 은행과 마을 회관도 표시됩니다. 하단 메뉴에서 주민·자원 관리·인벤토리·제작 공방·배치·꾸미기·건물을 바로 열 수 있고, 작은 화면에서는 관리 창이 아래쪽에 열립니다. 건물을 누르면 해당 관리 창이 열립니다. 배치·꾸미기에서는 보유 건물과 장식을 빈 땅으로 드래그하거나, 지도에서 옮기기를 누른 뒤 원하는 칸을 선택하세요. 좌표 입력과 방향키·Enter로도 정확하게 배치할 수 있습니다. 빈 땅을 드래그해 지도를 이동하고, 스크롤이나 버튼으로 확대·축소하세요. 건물을 철거하거나 복제할 수는 없으며, 이동 비용은 없고 생산량·주민 배치·탐험 효과도 바뀌지 않습니다. 이 화면은 정착지 내부 부지이며 미탐험 지역이나 자원을 새로 공개하지 않습니다. 정착지 이름으로 현황을 보고 Escape로 배치를 취소하거나 관리 창을 닫을 수 있습니다. 지도 위치·입력값·분류·펼침 상태·관리 창 스크롤은 메뉴 전환과 서버 갱신 후에도 유지됩니다. 탐험 지도와 같은 세션·언어를 사용합니다.

인벤토리에는 **유틸리티 장비·장식 아이템·수집품만** 보관합니다. 원자재와 기존 자원 창고는 별도이며 저장·확장 규칙도 바뀌지 않습니다. 장착하거나 배치한 아이템도 각각 1칸을 차지합니다. 제작 재료가 나오는 자원을 탐험으로 먼저 발견한 뒤 보유 자원으로 제작하세요. 거래소에서 재료만 구매해 발견 조건을 건너뛸 수는 없습니다.

시야 장비는 소모되지 않으며 한 번에 1개만 장착합니다. 미장착 시 반경은 4칸입니다. 제작한 장비의 시야가 더 넓을 때만 자동 장착되며, 이후 출발하는 탐험대부터 효과가 적용됩니다. 진행 중인 탐험의 반경이나 이미 탐험한 지역은 바뀌지 않습니다. 기존 횃불·등불 업그레이드는 추가 비용 없이 횃불·램프로 이전해 반경 6·8칸을 유지합니다.

아이템 보관함은 **가방(20칸) → 운반차(40칸, 금속 0.5 t + FTH$100) → 보관 상자(60칸, 금속 1.5 t + FTH$200) → 컨테이너(80칸, 금속 4 t + FTH$300) → 아이템 창고(100칸, 금속 10 t + FTH$400)** 순서로 확장합니다. 한 페이지에 20칸씩 표시하며, 확장할 때마다 페이지가 하나씩 추가됩니다. 비용은 다음 단계로 확장할 때 한 번만 내며 유지비는 없습니다. 기존 보관함 등급과 아이템은 유지되고 늘어난 용량이 바로 적용됩니다.

새 지역을 실제로 밝힌 탐험대는 위 기후별 발견 계획을 적용합니다. 기념품은 지형별 1개이며 새 지역이 없는 겹친 조사는 지급하지 않습니다. 자동화 이용권은 지형 난이도에 따라 1·4·12주 동안 유효합니다. 빈칸이 없으면 수령 대기로 보관하고 **발견물 받기**로 일부만 받아도 나머지 수량은 보존합니다. 원자재는 자원별 버튼에서 유료 수거하며 활성 수거권이 있어야 자동 수거합니다.

장식은 정착지 부지 안의 빈 땅 어느 칸에나 배치할 수 있습니다. 꽃 화분(목재 2 m³, 물 0.1 m³), 나무 벤치(목재 3 m³), 개척 깃발(목재 2 m³, 금속 0.1 t), 안뜰 분수(목재 3 m³, 물 0.4 m³, 금속 0.3 t), 정원 데크(목재 4.5 m³), 노점 천막(목재 5 m³, 금속 0.15 t)을 제작하세요. 재료 자원을 먼저 발견하고 보유 원자재로 제작해야 합니다. 장비·장식 제작량은 정착지 보급 묶음의 예산이며 휴대용 물건 한 개의 실제 재료 명세가 아닙니다.

정착 후 보유한 장식 아이템을 비용 없이 배치합니다. 건물과 장식은 각각 한 칸을 차지하며, 이미 사용 중인 칸·물·경계 밖에는 배치할 수 없습니다. 다른 아이템을 놓으려면 기존 장식을 먼저 옮기거나 인벤토리로 회수하세요. 회수해도 아이템은 사라지지 않고, 배치한 장식도 인벤토리 1칸을 차지합니다. 장식은 **외형만 바꾸며** 생산량·주민 배치·탐험 시야·보상에는 영향을 주지 않습니다. 위치는 서버에 저장되고 재시도로 중복 처리되지 않습니다. 기존 여섯 공간의 장식은 격자 위치로 이전되며, 보유 아이템이나 진행 중인 작업을 초기화하지 않습니다. 성장으로 추가되는 건물은 기존 배치를 밀어내지 않고 빈 칸을 찾아 생성됩니다.

### 주간 유료 수거와 보유 창고

배치된 주민이 게임 시간 1주를 채우면 자원이 수거 대기 상태로 보관됩니다. 상단은 목재·물·금속·석유·FTH$의 5개 핵심 버튼이며 일괄 받기 버튼과 저장량 50% 조건은 없습니다. 자원별 수거에서 모든 인원의 FTH$ 운송비를 정산합니다. 보유량과 수거 대기량은 창고 공간을 함께 사용하고 창고가 가득 차면 새 작업을 쉽니다.

저장 한도는 정수 회계 수량으로 계산합니다. 원자재는 `100 + 성장단계인덱스*100 + 창고레벨*500`과 다음 단계 최대 재료 요구량에 `창고레벨+1`을 곱한 값 중 큰 값을 사용합니다. 물은 원자재 보관량 +2,900과 `ceil(인구*35*1.5)*(2+저수지레벨)` 중 큰 값이며 화면에는 자원별 물리 단위로 환산합니다. 창고는 최대 10레벨이고 비용은 `목표레벨*(목재 8 m³ + 금속 0.2 t + FTH$50)`입니다. 급수 시설이 저장 공간을 직접 늘리지는 않습니다.

기존 보유량·소수 잔량·통화·주문 예치금·재시도 기록·완료 시각을 보존합니다. 이미 선불로 지불한 이전 작업에는 운송비를 다시 청구하지 않으며 새 작업부터 유료 수거 규칙을 적용합니다.

새 지역을 발견하는 탐험에서 자원별 자동 수거권을 획득할 수 있고 사용 전에는 거래소에서 거래할 수 있습니다. 사용 시 1개를 소모해 게임 시간 1·4·12주 동안 해당 자원을 자동 수거하며, 추가 사용하면 남은 기간에 합산됩니다. 자동 수거에도 같은 FTH$ 운송비가 필요합니다. 잔액이 부족하면 자원과 운송비를 대기 상태로 보존합니다. 같은 수거권을 여러 개 보유할 수 있으며 각각 가방 1칸을 차지합니다.

자동 탐험권·자동 주민 모집권도 같은 1·4·12주 소모형 이용권입니다. 인벤토리 또는 주민 관리의 **인원 배치·자동화**에서 사용하며 추가 사용 시 기간이 합산됩니다. 자동 탐험은 탐험대 1팀만 유지하고 수동 탐험대가 모두 돌아온 뒤 다음 팀을 보냅니다. 자동 주민 모집은 이전 모집 인원이 도착한 뒤 다음 모집을 시작합니다. 일반 활동과 동일한 FTH$ 비용·주택 보너스에 따른 모집비·물 공급 조건·최소 1주 완료 시간을 적용합니다. 조건이 부족하면 사유를 표시하고 게임 시간 하루마다 다시 확인합니다. 일시정지·기간 만료는 새 출발만 막으며 이미 비용을 낸 작업은 완료됩니다. 정지 중에도 이용 기간은 계속 줄어들고, 오프라인에서도 같은 일정과 비용으로 처리합니다.

수거 후 판매는 해당 자원의 채집 완료량을 거래소 가격으로 판매하고 대금에서 운송비를 정산하는 단일 거래입니다. 확인 창에 최소 순수령액을 표시하며 유동성 부족이나 가격 변경 시 전부 취소합니다. 통화는 발행하지 않습니다. 물을 판매할 때는 주민의 소비량을 고려하세요. 상단 인구 상태 표시를 누르면 정착지와 같은 주민 관리 창에서 모집·배치·탐험 파견·물 관리를 할 수 있습니다.

이 규칙은 게임 시스템이며 토큰 스테이킹이나 암호화폐 보상 프로그램이 아닙니다.

### 주민 모집

주민 모집에는 합류 인원 1명당 FTH$50이 필요합니다. FTH$ 잔액은 0으로 시작하므로 보유 자원을 먼저 판매하세요. 정착 지급금·주간 수입·탐험 통화 보상은 없습니다. 모집 전에 현재 비용을 확인할 수 있습니다. 한 번에 다음 중 더 큰 수의 주민이 합류합니다.

- 18명
- 현재 인구의 12%를 소수점 이하 버린 수

최종 모집 인원은 `floor(기본인원 * (1 + 주거단지레벨 / 4))`이며 합류 인원 1명당 FTH$50은 유지합니다. 주거 단지는 이후 시작하는 모집에만 적용하고 새 인구 제한은 만들지 않습니다.

정착 후 물이 충분하면 모집을 시작할 수 있지만, 첫 모집을 포함해 매번 **서버 게임 시간 1주(7일)**가 지나야 주민이 합류합니다. FTH$는 시작할 때 지불하며 모집 인원도 이때 확정됩니다. 모집 중인 인원은 주민 수와 작업 가능 인원에 포함하지 않습니다. 한 번에 한 팀만 모집하며 자동으로 반복하지 않습니다. 오프라인에서는 이미 시작한 모집만 완료되고 추가 모집 횟수는 쌓이지 않습니다. 기존 저장 기록의 주민과 남은 이전 쿨타임은 유지하며 가상의 모집 내역을 만들지 않습니다.

모집 비용과 진행 내역은 시작할 때 원자적으로 저장합니다. 완료 시각에 상태 조회나 행동을 처리하면서 주민 수와 현재 소속 연방·전체 인구 집계를 하나의 트랜잭션으로 한 번만 갱신합니다. 새 주민에게 이전 채집 보상을 소급 지급하지 않으며, 새 작업은 게임 시간 1주를 채워야 합니다. 재시도나 동시 요청으로 모집 결과를 중복 적용할 수 없습니다.

## 5. 인구와 거버넌스의 범위

상단에는 다음 인구를 표시합니다.

- **정착지:** 내 정착지의 가상 주민.
- **연방:** 내 정착지를 포함해 같은 이름의 가상 연방에 속한 서버 정착지의 주민.
- **전체:** 서버에 저장된 정착지의 주민. 만들어 낸 이웃 인구는 제외합니다.

미가입 상태에서는 연방 인구를 표시하지 않습니다. 전체 인구는 익명 세션이 만료된 비활성 정착지도 포함하며 세션을 정리한 뒤에도 합산 인구는 남습니다.

집계는 트랜잭션으로 갱신하고 인덱스 조회로 읽습니다. 실제 사람, 토큰 보유자, 민주적 대표성 또는 동일한 수의 실제 이용자를 검증한 통계가 아닙니다.

탭이 숨겨지거나 갱신이 실패하면 마지막 확인 값으로 표시를 마칩니다. 실패 시 마지막 확인 수치라는 안내를 표시하며, 최초 로딩에 실패해도 임의의 0을 만들지 않습니다. 동작 줄이기를 설정한 사용자와 화면 읽기 프로그램에는 중간 애니메이션 값 대신 실제 통계값을 제공합니다.

## 7. 구조와 신뢰

현재 구현은 다음을 사용합니다.

1. TypeScript/Vite 브라우저 클라이언트.
2. Node HTTP 시뮬레이션 API.
3. 교체 가능한 저장소 인터페이스.
4. 세션, 서버 검증 상태, 요청 처리 결과, 시간 기준점, 인구 집계용 SQLite.

브라우저는 허용된 명령, 예상 버전, 요청 식별자만 보냅니다. 서버는 세션 쿠키로 소유자를 확인하고 신뢰할 수 있는 시간을 얻어 요청을 검증한 다음 승인된 변경을 한 번에 반영합니다.

### 구현된 보호 장치

- 무작위 세션 자격 증명의 해시 저장, HttpOnly 쿠키, SameSite 제한.
- 세션에 연결된 CSRF 토큰, Origin 및 Fetch Metadata 검사.
- 엄격한 요청 항목 검증. 클라이언트는 시각, 보유량, 배속, 보상량을 정할 수 없습니다.
- 소비·수령·주민 모집·버전·인구 집계의 트랜잭션 처리.
- 마지막 성공 요청의 처리 결과를 저장해 재시도 시 중복 적용 방지.
- 상태 조회 시 주간 생산량과 운송비를 트랜잭션으로 한 번만 정산하며, 자원을 자동으로 수령하지 않는 처리.
- 자원 한도, 수령 기준, 제한된 요청 크기, 실제 시간 기준의 남용 제한.
- 내보낸 데이터나 브라우저 저장 보유량을 신뢰해 가져오는 경로 없음.

**CSRF 검사는 실제 사람이 플레이 중임을 증명하지 않습니다.** 정상 세션을 쓰는 스크립트도 토큰을 얻어 올바른 요청을 보낼 수 있습니다. 목표는 세션이 받을 수 있는 양을 제한하는 것이지 완벽한 봇 차단을 약속하는 것이 아닙니다.

익명 세션은 다중 계정 자원 수집을 방지하거나 1인 1표 신원을 보장하지 않습니다.

### 로컬 프로토타입의 한계와 클라우드 적용

프로토타입은 세션 수와 프로세스 내부 요청 제한을 의도적으로 제한합니다. 인증·독립 감사·운영 환경 보안 강화가 완료되었거나 수백만 이용자를 지원한다고 검증된 서비스가 아닙니다.

운영 서비스에는 인증된 신원과 복구, 감시되는 서버 시간, 공유 남용 제한, 안정적인 분산 저장소, 통일된 시간 설정, 트랜잭션 또는 조건부 쓰기 보장, 백업, 감사 가능성, 부하 테스트, 보안 검토, 관할 지역에 맞는 법률·개인정보 검토가 필요합니다.

정확한 전체·연방·정착지·금속 집계는 규모가 커지면 공유 쓰기 병목이 됩니다. 분할 집계나 영속적이고 중복 처리에 안전한 아웃박스와 표시 지연 정책을 갖춘 사전 집계는 가능한 개선안이지 이미 구현된 분산 기반 시설이 아닙니다. 공개 통계는 짧은 공유 캐시를 허용하지만 운영 배포에서는 실제 캐시 설정과 읽기 계층 부하 테스트가 필요합니다.
