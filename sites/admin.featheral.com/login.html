Featheral Admin

Root administrators sign with the origin or Dollar reserve wallet. Approved App administrators can use their shared World profile or an authorized signing wallet.

No password, network switch, gas or transaction is needed.

Need help signing in?

Unlock your Ethereum wallet and select the origin or Dollar reserve account. If several wallet extensions are installed, choose the correct signing wallet above. Approve both the connection and the sign-in message in your wallet.

A wallet connected on another Featheral site is not automatically connected to Admin. Server updates end Admin sessions; sign in again after an update.
